## Overview

Moonlight is an open-source NVIDIA GameStream client that streams your PC games at up to 4K 120 FPS with hardware-accelerated H.265 decoding to phones, tablets, Macs, and smart TVs.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Moonlight** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **4K 120 FPS** | Hardware-accelerated 4K HDR streaming at up to 120 frames per second |
| **H.265 Decoding** | HEVC decode on every supported platform for 50% less bandwidth |
| **Controller Support** | Maps connected gamepads, keyboards, and mice to the host PC |
| **WAN Streaming** | Automatic port detection for remote streaming outside the local network |
